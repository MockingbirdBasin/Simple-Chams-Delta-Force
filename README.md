## Features

- **7 colour presets** – neon, pastel, tactical, and more.
- **Adaptive brightness** – adjusts to in‑game lighting automatically.
- **Distance fade** – colours gradually blend with environment at range.
- **Toggle hotkey** – enable/disable with a single key.
- **Performance‑optimised** – designed for high FPS gameplay.
- **Backup utility** – save your original shader settings.
- **Visual reference sheet** – all colours displayed in a single image.
- **Cross‑resolution support** – works on any screen size.
- **Simple installation** – copy‑paste files into the game directory.
- **Compatibility notes** – tested with latest Delta Force updates.

## Requirements

- Windows 10 / 11 (64‑bit)
- Delta Force (official client)
- DirectX 11 or 12 capable GPU

## Usage

1. Extract the files to a folder.
2. Copy the shader files to the game's `Config` or `Shaders` folder (see guide).
3. Launch Delta Force in borderless mode.
4. Press `F2` to cycle through colour schemes.
5. Adjust intensity using the provided slider tool.
6. Revert using the backup script if needed.

## About the project

Simple-Chams-Delta-Force is an educational repository that provides shader configuration templates for Delta Force. It demonstrates how colour filtering can be used to enhance player visibility without modifying game binaries – purely through external graphics settings.
